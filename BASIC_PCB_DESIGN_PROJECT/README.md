# Beginner PCB Design Project

This project represents my first hands-on experience with PCB design as an Electronics and Communication Engineering (ECE) student.

## Project Overview
- Designed a basic electronic circuit schematic.
- Converted the schematic into a PCB layout.
- Learned component placement, routing, and basic design rules.
- Understood common beginner mistakes and how to correct them.

## Tools Used
- PCB Design Software: EasyEDA (or the tool you used)
- Basic Electronics Components

## What I Learned
- Reading and understanding datasheets  
- Schematic creation  
- Footprint assignment  
- PCB routing and layout basics  
- Importance of grounding and track width  
- Debugging design errors  

This project helped me build confidence in hardware design and motivated me to learn more about real-world PCB development.
